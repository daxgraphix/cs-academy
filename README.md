# CS Academy | Practical AI & Digital Skills for East Africa

CS Academy is East Africa's premier technology learning platform, dedicated to bridging the digital divide by delivering high-impact, Swahili-first training in Artificial Intelligence, Cybersecurity, and Web Development.

**Live URL:** [https://academy.cyberswahili.co.tz](https://academy.cyberswahili.co.tz)

---

## 🚀 Mission & Vision
**Mission:** To eliminate language and cost barriers in technology education, empowering Africans to participate fully in the global digital economy.
**Vision:** To be the leading engine for digital literacy and workforce readiness across the Swahili-speaking world.

---

## 💎 Core Values
1.  **Swahili-First:** Complex technical concepts explained in clear Kiswahili while retaining essential English industry terminology.
2.  **Practical-Driven:** Every lesson leads to a tangible output—a report, a piece of code, or a business proposal.
3.  **Zero-Friction Access:** Optimized for low-bandwidth environments (2G/3G) and payable via local Mobile Money (M-Pesa, Tigo Pesa, Airtel Money).
4.  **Responsible AI:** Promoting ethical, safe, and privacy-aware use of AI tools.

---

## 🧠 The SMART Framework
Our proprietary pedagogy ensures learners don't just "watch" but "master":
-   **S (Understand):** Build a solid conceptual foundation of how technology works.
-   **M (Master):** Mudu (Master) the exact tools, prompts, and workflows.
-   **A (Apply):** Translate theory into concrete daily outputs (e.g., project briefs).
-   **R (Review):** Critically evaluate outputs for accuracy and bias.
-   **T (Trust):** Use technology responsibly with privacy and ethics in mind.

---

## 🛠 Platform Features
-   **Interactive Quizzes:** Instant auto-grading to confirm conceptual mastery.
-   **Verifiable QR Certificates:** Tamper-proof PDF certificates for LinkedIn and CVs.
-   **Digital Shop:** Premium ebooks, UI kits, and "ready-to-use" prompt packs.
-   **Live Vibe Coding:** Real-time collaborative sessions building apps using AI.
-   **Invite & Earn:** A referral system where learners earn rewards and cash payouts.
-   **Bilingual Teaching:** Seamlessly switching between Swahili explanations and English technical terms.

## 📦 Delivery Channels
We meet learners where they are, regardless of their internet speed:
1.  **WhatsApp Micro-Learning:** Daily audio lessons and PDFs for ultra-low data users.
2.  **Self-Paced Video Platform:** On-demand HD video tracks for flexible scheduling.
3.  **Live Virtual Cohorts:** Interactive Zoom/Meet bootcamps with real-time coaching.
4.  **Workshops & Seminars:** High-impact half/full-day sessions for institutions.
5.  **Corporate On-Site:** Deep-dive, physical training delivered at your venue.
6.  **Conferences & Keynotes:** Expert speaking engagements for technology summits.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production
```bash
npm run build
```
